# AmbiencePunk

Welcome to AmbiencePunk, a project that allows you to create your own ambient soundscapes!

## Project Link

You can find the project live at: [https://andrewcoder43.github.io/AmbiencePunk/](https://andrewcoder43.github.io/AmbiencePunk/)

## How It Works

AmbiencePunk lets you mix and match different weather sounds to create a unique atmosphere. Here's how to use it:

*   **Play Sounds:** Click on the individual weather icons (e.g., rain, snow, sun) to play the corresponding sound.
*   **Stop Sounds:** Click the same weather icon again to turn off the sound.
*   **Control Volume:** Adjust the volume of each sound using the slider button.
*   **Change Background:** Use the dropdown menu to select a background that matches your desired ambience (rain, snow, sun).
